# ⚡ Agenda semana

Sistema de agendamento e gestão de tarefas desenvolvido para otimizar o fluxo de trabalho e serviços. Este projeto foi criado como parte dos meus estudos em **Análise e Desenvolvimento de Sistemas (Estácio)**, aplicando conceitos de manipulação de DOM, persistência de dados e design responsivo.



## 🚀 Funcionalidades

- **C.R.U.D. Completo**: Adicionar, Listar, Editar e Excluir tarefas.
- **Persistência de Dados**: Utiliza `localStorage` para manter as tarefas salvas mesmo após fechar o navegador.
- **Checklist de Conclusão**: Marque serviços finalizados com feedback visual imediato.
- **Bloco de Edição Interno**: Edição de tarefas realizada através de uma janela modal customizada, sem uso de prompts nativos.
- **Design Responsivo**: Interface adaptável para uso em computadores e dispositivos móveis.
- **Vanilla Stack**: Desenvolvido 100% com tecnologias nativas (HTML5, CSS3 e JavaScript), sem dependência de frameworks externos.

## 🛠️ Tecnologias Utilizadas

* **HTML5**: Estruturação semântica do sistema.
* **CSS3**: Estilização moderna, variáveis de cor e layout flexível (Flexbox).
* **JavaScript (ES6+)**: Lógica de programação, manipulação de arrays e objetos, e integração com a Web Storage API.
